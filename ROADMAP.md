## SEO-чеклист для каждой страницы

### Meta-теги
- [ ] `<title>` — 50-60 символов, уникальный, с ключевыми словами
- [ ] `<meta name="description">` — 150-160 символов, продающий
- [ ] `<meta name="keywords">` — 5-10 ключевых слов
- [ ] `<link rel="canonical">` — канонический URL

### Open Graph (для соцсетей)
- [ ] `og:title`
- [ ] `og:description`
- [ ] `og:image`
- [ ] `og:url`
- [ ] `og:type`

### Schema.org (JSON-LD)
- [ ] `Product` — для карточек чая
- [ ] `Article` — для энциклопедических статей
- [ ] `Organization` — для информации о магазине
- [ ] `BreadcrumbList` — хлебные крошки
- [ ] `FAQPage` — для вопросов и ответов

### Структура
- [ ] Один H1 на страницу
- [ ] Логическая иерархия H2-H6
- [ ] Семантические теги HTML5
- [ ] Alt-тексты для изображений
- [ ] ЧПУ (человеко-понятные URL)
