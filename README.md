# 🍵 Teapedia — Энциклопедия китайского чая

Интерактивная энциклопедия китайского чая для проекта **THE CHAI**.

## Что внутри

- **Каталог чаёв** — 8 сортов с подробными карточками
- **QR-интеграция** — каждый чай имеет уникальный URL для QR-кода на упаковке
- **Рецепты заваривания** — температура, дозировка, время, посуда
- **История и польза** — для каждого сорта
- **Энциклопедия** — структура для статей (терруар, посуда, церемония, наука)
- **Адаптивный дизайн** — работает на телефонах, планшетах и десктопах

## Как добавить новый чай

1. Откройте `data/teas.json`
2. Скопируйте блок любого чая и вставьте в конец массива
3. Измените поля:
   - `id` — уникальный идентификатор (латиница, через дефис)
   - `name` — название на русском
   - `nameCn` — иероглифы
   - `category` — green / white / oolong / red / dark / yellow
   - `origin`, `altitude`, `flavor`, `description`, `history`, `health`
   - `brewing` — объект с temp, amount, time, vessel, infusions
   - `price` — цена или "от X ₽"
   - `qrUrl` — URL для QR-кода
4. Сохраните и закоммитьте

## Как добавить фото

1. Загрузите фото в папку `images/teas/`
2. Назовите файл так же, как `id` чая + `.jpg`
3. Например: `da-hong-pao.jpg` для чая с id `da-hong-pao`
4. В `teas.json` укажите путь: `"image": "images/teas/da-hong-pao.jpg"`

## Как развернуть на GitHub Pages

1. Загрузите все файлы в репозиторий на GitHub
2. Перейдите в **Settings** → **Pages**
3. В разделе **Build and deployment** выберите:
   - Source: **Deploy from a branch**
   - Branch: **main** → **/ (root)**
4. Нажмите **Save**
5. Через 1–2 минуты сайт будет доступен по адресу:
   ```
   https://mleontev111-max.github.io/teapedia/
   ```

## Как привязать свой домен (teapedia.ru)

1. Купите домен `teapedia.ru` (если ещё не куплен)
2. В настройках DNS домена добавьте запись:
   - **Тип:** A
   - **Имя:** @ (или teapedia.ru)
   - **Значение:** `185.199.108.153`
   - **TTL:** 3600

   Также добавьте запись:
   - **Тип:** A
   - **Имя:** @
   - **Значение:** `185.199.109.153`

3. В GitHub репозитории перейдите в **Settings** → **Pages**
4. В разделе **Custom domain** введите: `teapedia.ru`
5. Нажмите **Save**
6. Дождитесь проверки DNS (может занять до 24 часов)
7. Поставьте галочку **Enforce HTTPS** (бесплатный SSL-сертификат)

## QR-коды для упаковок

Для каждого чая в `teas.json` указан `qrUrl`. Используйте его для генерации QR-кода:

- Онлайн: [qr-code-generator.com](https://www.qr-code-generator.com)
- Или через Python:
  ```python
  import qrcode
  qr = qrcode.make('https://teapedia.ru/tea/da-hong-pao')
  qr.save('da-hong-pao-qr.png')
  ```

Наклеивайте QR-код на упаковку — клиент сканирует и попадает на страницу чая с историей и рецептом.
