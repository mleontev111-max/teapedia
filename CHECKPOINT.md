## Система чекпоинтов

Создавать новый checkpoint:
- после каждой законченной фазы;
- перед крупной перестройкой;
- после массового импорта/редактирования;
- после доменных, SEO, API и QR изменений;
- перед рискованными изменениями.

Каждый checkpoint должен фиксировать:
1. дату и версию;
2. стабильный commit;
3. рабочие компоненты;
4. изменения с предыдущей точки;
5. структуру;
6. прогресс контента;
7. известные проблемы;
8. следующий шаг;
9. способ восстановления.
